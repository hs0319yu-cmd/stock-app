在庫アプリ PWA / iPhoneアイコン修正版

アップロードされた index.html の既存機能はそのままにし、head部分へPWAメタ情報を追加しました。
同じ公開フォルダに次の4ファイルを必ず配置してください。

- index.html
- manifest.json
- icon-192.png
- icon-512.png
- apple-touch-icon.png

重要:
1. GitHub Pagesなどで、ファイルを同じ公開フォルダへアップロードしてください。
2. manifest.json だけでなく、アイコン画像も公開URLで開ける必要があります。
3. iPhoneではSafariで公開URLを開き、共有ボタン→「ホーム画面に追加」を使ってください。
4. 以前追加したホーム画面アイコンは削除し、再追加してください。
5. サイトのURLが変わると別アプリ扱いになることがあります。
